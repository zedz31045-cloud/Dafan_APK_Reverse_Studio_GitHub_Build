# Dafan APK Reverse Studio

مشروع Android Studio بلغة Java لتحليل APK محليًا. ليس ملف EXE، ولا يقوم بتشغيل الكود الموجود داخل APK.

## الميزات المنفذة في هذا المشروع
- اختيار APK من مدير ملفات Android عبر Storage Access Framework؛ يمكن اختيار ملف من Downloads.
- نسخ الملف المختار إلى ذاكرة التخزين المؤقت الخاصة بالتطبيق للتحليل، دون تعديل الملف الأصلي.
- استخراج بيانات الحزمة التي يتيحها Android PackageManager: اسم الحزمة، رقم الإصدار، اسم الإصدار، target SDK، الصلاحيات والمكوّنات التي أمكن قراءتها.
- عرض أسماء الملفات والأحجام داخل أرشيف APK (APK هو ZIP في بنيته الخارجية).
- استخراج سلاسل ASCII القابلة للطباعة من ملفات classes*.dex كمسح أولي، وليس تفكيكًا أو decompilation.
- حساب بصمة SHA-256 محليًا.
- تصدير التقرير النصي إلى المكان الذي يختاره المستخدم، بما فيه Downloads.
- اختبارات وحدات بسيطة لـ SHA-256 واستخراج السلاسل النصية.

## حدود واضحة
- لا يفك هذا المشروع صيغة Android Binary XML إلى Manifest مقروء؛ يتطلب ذلك أداة مثل Apktool.
- لا يستعيد مصدر Java/Kotlin الأصلي. سلاسل DEX الخام ليست decompilation.
- لا يعدّل APK ولا يعيد بناءه ولا يوقّعه.
- لا يرفع APK أو بصمته إلى أي خدمة. إذن INTERNET موجود لتوسعات لاحقة فقط ولا توجد وظيفة شبكة في النسخة الحالية.
- قراءة بعض البيانات تعتمد على Android PackageManager وقد لا تنجح لكل الملفات أو الصيغ.
- فحص DEX محدود بحد أقصى 32 MiB لكل ملف DEX، ونتائج السلاسل محدودة إلى 1000 نتيجة لتقليل استهلاك الذاكرة.

## المتطلبات
- Android Studio حديث أو بيئة Gradle متوافقة.
- JDK 17.
- Android SDK Platform 35.
- Android Gradle Plugin 8.6.1 وGradle 8.7 (سيتم تنزيل Gradle من الإنترنت عند أول بناء).

## البناء إلى APK
1. فك ضغط المشروع.
2. افتح مجلد `Dafan_APK_Reverse_Studio` في Android Studio.
3. وافق على مزامنة Gradle وتنزيل SDK إذا طُلب ذلك.
4. شغّل اختبارات الوحدة من Android Studio، أو من طرفية مجهزة نفّذ `gradle test`.
5. من القائمة اختر **Build → Build APK(s)**.
6. عند نجاح البناء، يكون ملف debug APK عادةً في `app/build/outputs/apk/debug/app-debug.apk`.

لا يتضمن ZIP ملف `gradlew` التنفيذي أو `gradle-wrapper.jar`؛ إذا أردت استخدام wrapper، أنشئه من Android Studio أو نفّذ `gradle wrapper --gradle-version 8.7` في بيئة فيها Gradle.

## الاستخدام
1. شغّل التطبيق.
2. اضغط اختيار APK وحدد الملف.
3. استخدم أزرار تحليل الحزمة، عرض المحتويات، سلاسل DEX أو SHA-256.
4. اضغط تصدير التقرير واختر Downloads أو مجلدًا آخر.

## الاختبارات والتحقق
اختبارات JUnit موجودة في `app/src/test`. ملفات المشروع تم إعدادها هنا، لكن لم يتم تشغيل بناء Android/Gradle في بيئة Windows أو على جهاز فعلي؛ لذا لا أدّعي أن APK جاهز أو أن البناء اختُبر بنجاح. يجب تنفيذ البناء والتحقق منه في Android Studio أو بيئة متوافقة.
